Compatible Foundry VTT v13.

---

# 🇫🇷 Français

## Présentation

Ce système permet de jouer à **C.O.P.S** sur Foundry VTT avec :

- Fiche personnage complète
- Gestion des compétences et spécialisations
- Gestion des attitudes de combat
- Jets automatisés (seuil + succès requis)
- Application des dégâts depuis le chat
- Gestion de l’adrénaline (activable/désactivable par compétence)
- Wizard de création de personnage

Le système suit les règles officielles du jeu.

---

## Installation

### Installation via manifest (recommandée)

1. Foundry → Configuration → Systèmes
2. Installer un système
3. Coller l’URL du manifest

(URL à ajouter après publication GitHub)

### Installation manuelle

1. Télécharger le fichier `.zip` depuis la section "Releases" du repository GitHub.
2. Ouvrir le dossier d’installation de Foundry VTT. Par défaut sous Windows, il se trouve généralement ici : C:\Users\VotreNom\AppData\Local\FoundryVTT\Data\systems\
3. Extraire le dossier `cops` à l’intérieur du dossier `systems`.
Vous devez obtenir : ...\FoundryVTT\Data\systems\cops\system.json
4. Redémarrer Foundry VTT.

# 🇬🇧 English

## Overview

This system allows you to play **C.O.P.S** in Foundry VTT.

Features include:

- Complete character sheet
- Skills and specializations
- Combat attitudes
- Automated rolls (threshold + required successes)
- Damage application from chat
- Adrenaline management (toggle per skill)
- Character creation wizard

The system follows the official rules of the game.

---

## Installation

### Manifest installation (recommended)

1. Foundry → Configuration → Systems
2. Install System
3. Paste the manifest URL

(URL will be added after GitHub release)

### Manual installation

1. Download the `.zip` file from the "Releases" section of the GitHub repository.
2. Open your Foundry VTT data folder. On Windows, it is usually located at: C:\Users\YourName\AppData\Local\FoundryVTT\Data\systems\
3. Extract the `cops` folder inside the `systems` directory. You should end up with: ...\FoundryVTT\Data\systems\cops\system.json
4. Restart Foundry VTT.
